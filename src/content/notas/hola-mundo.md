Este es el primer post de ejemplo del sitio, construido con
[Astro](https://astro.build) a partir de una plantilla **minimalista** y fácil
de mantener.

## Por qué Astro

El contenido va en Markdown (como este archivo) y el sitio final es HTML ligero,
sin un framework pesado en el navegador.

Para crear un post nuevo solo copias este archivo, cambias el bloque de arriba
(el *frontmatter*) y escribes. Así de simple:

```markdown
---
title: Mi nuevo post
description: Una línea que resume el post.
pubDate: 2024-02-01
tags: ["idea"]
---

Aquí va el contenido...
```

Borra esta nota y escribe la tuya.
